> 智慧物业 V2 · 业主自助 + 社区内容的高保真原型。
> uni-app（Vue 3 + Vite，**JS 模板**）· H5 优先 · 数据与设计变量**只读复用** `03-原型`。
>
> 上一版（v0.1）是"授权 → 实名 → 绑定 → 首页"的八屏强制流程；
> 本版按 2026-11-01 的口径重构成 **4 个 tab + 按需认证**，并补齐内容侧（邻里 / 生活）。

## 四、四条硬口径（都写死在代码里）

### 4.1 登录 ≠ 认证（本版最大的结构改动）

```
L0 游客   session=null            公告 / 邻里 / 生活 / 公共报修 都能用
L1 登录   手机号（验证码）         评论 / 报名 / 投票 / 想要
L2 认证   手机号+姓名+证件后四位 与档案、房屋三项全中 → 秒过
          · 命中业主 → 业主（全部）
          · 命中家属 → 家属（缴费/报修/开门；看不到租约金额、不能管成员）
          · 命中租客 → 租客（报修/开门；看不到业主账单；信息不全则禁门禁）
          对不上 → 人工审核（必须上传购房合同/房产证，否则物业无法核验）
```

门禁是**动作级**的（`utils/guard.js`）：`gateLogin()` / `gateOwner()` / `gatePerm('bills')`。
不再有"启动就 reLaunch 到绑定页"——那会让想报名活动的人第一步就走掉。

### 4.2 家庭账单：多房合并，但合并的是"付款动作"

- 合计 = 已绑全部房产 + 本人名下**不挂房的车位费**（`bills` 里 1,344 张 `houseId` 为空，只按房过滤会漏钱）；
- 页面先给总账，再**按房分组**给小计 —— 业主必须看得出"哪套房欠的"；
- 一次支付可覆盖多房多张账单，但订单 `lines` 逐条带 `houseId`，后台仍按房拆分入账、退费、催缴。
- 认证是**逐套绑**：绑完一套，首页会提示"名下还有 N 套未绑定"，点进去补绑（否则永远看不到另一套的账）。

### 4.3 增项确认：合并进本单，只补差额

125（下单预付）+ 80（现场增项）= 205 总额；确认后 `payStatus` 回到「未支付」，
`dueFee = totalFee - paidAmount` 才是要付的钱（补付页会写明"已预付 ¥125，本次只付差额 ¥80"）。
**只改总额不改支付状态，那 80 块就永远收不上来**（v0.1 踩过）。

### 4.4 支付只到「模拟成功」

`payOrder`（30 分钟有效期）→ 点「模拟支付成功」才置已支付；真接入替换点写在 `api/mp.js` 的 `simulatePay()` 注释里：
服务端 JSAPI 下单 → `wx.requestPayment` → 渠道回调验签+幂等 → 才置已支付，前端不判断成功。

### 缺口（本轮明确不做）

1. **生活 tab 真实交易** —— 商业后台未开发。
2. **闲置/邻里业主自主发布** —— 需内容安全审核与运营人力，下一版。
3. **法定业主表决** —— 投票问卷只是意见征集；法定表决要面积+人数双过半、实名留痕、可公证。
4. **在线过户 / 产权变更** —— 设计稿有此入口，涉及原业主确认与资料核验，P2。
5. **消息中心 / 订阅消息** —— 目前只有页面内提示。
6. **门禁、停车、访客的完整闭环** —— 需硬件与后台。
7. **员工端与本工程不共享运行时** —— 两端一致性只体现在契约与状态机；员工端至今没把增项写回 `workOrders[].addons`，所以报修详情保留了「模拟加项」入口，员工端补齐后要删掉。

## 八、这一轮踩到的坑（都在代码注释里）

1. **同一楼栋两个单元都有 0501**：按文字点房间会点到隔壁单元 —— 房间格子要有 `id="room-{houseId}"`。
2. **三类人都带 ownerId**：家属挂在业主上、租客也记着业主，靠 `ownerId` 判身份会把租客当成业主 → 用 `houseIds[] / memberId / tenantId` 区分。
3. **Bar 组件的 right slot 会吃掉默认按钮**：写了 `#right` 就没有主按钮了 —— 需要两个动作时，把次要动作放正文。
4. **只清 localStorage 不重载**：store 在模块初始化时读缓存，换身份必须整页 reload，否则登录页会以为还登录着。
5. **`<text>` 默认 inline**：同容器两个 text 会粘成一行，凡是"标题+说明"两行结构都要 `display: block`。
6. **`padding` 简写里混 `constant()`**：Chrome 不认会让整条声明失效，`env()` 与 `constant()` 各写一条。
