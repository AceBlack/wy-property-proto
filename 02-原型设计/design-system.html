设计原则

Principles

四条原则贯穿所有页面，优先级自左向右递减。

01

轻量

全新视觉风格，轻量化设计。去掉重边框与重底色，用留白和投影区分层级。

02

简约

卡片式布局，视觉体验简洁明了。一个卡片只回答一个问题。

03

目标清晰

目标传达清晰，流程简化。主操作唯一、主色唯一，次操作一律降级。

04

提升效率

层级清晰，减少认知成本。常用筛选默认填好，高频操作一步直达。

色彩系统

Colors

主色靛蓝紫负责「交互」，辅色薄荷青负责「强调」，两者通过品牌渐变绑定；语义色只用于状态，不参与装饰。

品牌色Brand

品牌渐变 · 135°
用于 Logo、登录页、驾驶舱标题、空态插画。页面内少量点缀。
深海军蓝 · 侧栏
仅用于侧边导航与页头 Logo 区，内容区禁止使用深底。

✓ 正确用法

  • 指标语义：达标 = 绿 #2ED9A3，未达标 = 红 #FF6B6B（运营指标，非金融行情，不用红涨绿跌）
  • 状态标签：light-9 底 + 品牌字色 + 6px 圆点前缀
  • 文字颜色只用四档：#1F2540 主文 / #4A5168 常规 / #8A94B0 辅助 / #B3BAD0 占位

✕ 禁止

  • 语义色大面积铺底作装饰（整块红色卡片、绿色按钮当主按钮）
  • 同一页面出现 3 种以上强调色
  • 内容区做深色底（深色仅属于侧栏）

落地规则

Implementation

Element Plus 变量全覆盖，第三方组件零适配自动跟随新风格。

Token 分组关键变量取值说明
品牌主色--el-color-primary#5B6CFF含 light-3~9 / dark-2 全套，覆盖 EP 默认蓝
品牌辅色--biz-accent / --biz-gradient#2ED9A3 / 135° 渐变积极批量动作 / 达标强调
语义色--el-color-success 等#2ED9A3 / #FF9F40 / #FF6B6B / #8A94B0成功=薄荷青，与辅色同源
页面背景--el-bg-color-page#F1F2FA浅紫调，不再用纯灰
文字四档--el-text-color-*#1F2540 → #B3BAD0偏紫蓝调的中性色
圆角--el-border-radius-base6 / 10 / 12 / 999控件 6、卡片 10、面板 12、胶囊 999
侧栏--biz-sidebar-*#101F42 + 选中渐变选中项左缘 3px 青绿指示条
投影--biz-shadow-*rgba(31,37,64,.05) / 浮层 .12静态极淡，浮层才明显
图表echarts-theme.js · paletteC1 #5B6CFF … C8 #A0A8C8与 tokens.css --chart-c1..c8 严格一致
引入顺序：import 'element-plus/dist/index.css' 之后 import '@/styles/tokens.css'，否则变量覆盖不生效。
改造范围：仅替换 tokens.css + echarts-theme.js 两个文件，页面代码与组件结构零改动即可整体换肤 —— 这也是 L0 设计系统先行的意义。
