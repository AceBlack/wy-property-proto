## 一、色彩

### 1.1 品牌色

| 用途 | 值 | 说明 |
|---|---|---|
| 主色 Primary | `#5B6CFF` | 主按钮、选中、链接、图表主序列 |
| 主色 hover | `#4D5EF7` | |
| 主色 active | `#3F4EE0` | |
| 主色浅底 | `#EEF0FF` | 选中行、激活导航、当前页 |
| 辅色 Accent | `#2ED9A3` | 正向数值、达标标识，**不做交互色** |
| 辅色深 | `#1DB385` | |

**强调色上限：1 个主色 + 1 个辅色 + 4 个语义色。不得引入第五个。**

### 1.2 语义色（填充与文字分两档，不可混用同一值）

| 语义 | 填充（图标 / 圆点 / 图表） | 文字（浅底上的文本） |
|---|---|---|
| 成功 | `#2ED9A3` | `#12B98A` |
| 警告 | `#FF9F40` | `#D98A1F` |
| 危险 | `#FF6B6B` | `#EC4D63` |
| 信息 | `#8A94B0` | `#7A52E0` |

浅底填充用对应 `light-9`：成功 `#E6FAF3`、警告 `#FFF5EB`、危险 `#FFF0F0`。

### 1.3 中性色

| 角色 | 值 | 用途 |
|---|---|---|
| 页面底 | `#F7F8FA` | 内容画布 |
| 卡片底 | `#FFFFFF` | 瓦片、筛选面板、表单分区 |
| 填充底 | `#F4F5FC` | 图标方块、只读块 |
| 控件边框 | `#E3E6F2` | 输入框、按钮描边 |
| 分割线 | `#EEF0F8` | 区块之间 |
| 行分割线 | `#F6F7FA` | 表格行之间 |
| 侧栏右边线 | `#F0F2F6` | |
| 文本一级 | `#1F2540` | 标题、数值、表格主字段 |
| 文本二级 | `#4A5168` | 正文、表格次字段 |
| 文本三级 | `#8A94B0` | 辅助、表头、标签名 |
| 文本四级 | `#B3BAD0` | 占位符、极弱信息 |
| 文本禁用 | `#C3C9DD` | |

**注意**：页面底与卡片底只差 8 个色阶。**不要为了强调卡片而加深页面底**——那是早期方案，会让整页发灰。

### 1.4 交互态底色（最易被忽略的一组）

| 场景 | 值 | 说明 |
|---|---|---|
| 表格行 hover | `#F2F4FF` | 与白底差 13 阶；行两端 8px 圆角 |
| 菜单 / 列表项 hover | `#F5F6FF` | 面积小、频次高，可比表格更轻 |
| 选中 / 激活底 | `#EEF0FF` | 当前页、导航激活、勾选行 |
| 按下底 | `#E4E7FF` | |
| 禁用底 | `#F4F5FA` | |
| 只读底 | `#F7F8FC` | |

**禁止**用 `#FAFBFD` 这类接近白色的值做 hover——实测肉眼不可见，等于没有反馈。

## 二、字阶

**只用这 6 档。** 不允许 11.5 / 12.5 / 13.5 这类 0.5px 递进。

| 档位 | 字号 | 字重 | 用途 |
|---|---|---|---|
| Caption | 12px | 400 | 表头、KPI 标签、辅助说明、胶囊角标 |
| Body-S | 13px | 400 | 表格正文、工具条控件、状态标签 |
| Body | 14px | 400 | 表单标签、区块内正文、按钮 |
| Subtitle | 16px | 500 | 区块标题 |
| Title | 17px | 500 | 页面标题（表单页页头） |
| Num | 26px | 600 | KPI 数值 |

数字统一 `font-variant-numeric: tabular-nums`，金额列右对齐。

> 原型中残留少量 `12.5px`（状态文字、分页页码）和 `11.5px`（小角标），属历史实现，**正式前端一律并入 13 / 12**。

## 三、间距

8pt 栅格，允许 4px 半格。**只用这 9 个值**：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`

| 场景 | 值 |
|---|---|
| 页面内容左右内边距 | 24 |
| 内容区顶部 | 12 |
| 瓦片之间 / 区块之间 | 12 |
| 瓦片内边距 | 13 / 16 |
| 图标与文字 | 6 |
| 表格单元格左右 | 12 |
| 工具条内控件间距 | 8 |

## 六、组件规格

### 6.1 表格（最高频，优先级最高）

- 行高 **46**，表头 **38**
- 表头：12px / 400 / `#8A94B0` / **无底色** / 下边框 `#EEF0F8`
- 行：13px / `#4A5168`，下边框 `#F6F7FA`
- **hover：整行底色 `#F2F4FF`，两端 8px 圆角**
- **不启用斑马纹**
- 金额与数量列右对齐 + 等宽数字
- 首列勾选宽 42
- **末列不放操作按钮**，点整行开右侧抽屉
- 空态用统一空态组件（带引导动作），不用浏览器默认「暂无数据」
- 表格背景透明，铺在画布上

### 6.2 分页

- 页码 28×28、圆角 8、字号 13、默认透明底、**无描边**
- 当前页：底 `#EEF0FF` + 主色文字 + 500 字重（**不用主色实底**，太重）
- hover：底 `#F1F2F6`
- 与表格右对齐

### 6.3 工具条

- 一行放完，高 40，不换行
- 顺序：搜索 → 主筛选（1–2 个）→ 快捷视图胶囊 → 更多筛选 → ⓘ → 右侧操作
- **主按钮每屏只有 1 个**，放最右
- 搜索框宽 268，控件高 32
- 页面说明文字不占位，收进 `ⓘ` 弹层

### 6.4 快捷视图胶囊

- 高 32、圆角 999、13px
- 未选中：透明底 + `#4A5168`；选中：白底 + `#1F2540` + `0 1px 2px rgba(16,24,40,.08)`
- 右侧计数 11px / `#B3BAD0`，选中时变主色
- 再次点击已选中项 = 取消

### 6.5 更多筛选面板

- **就地展开，不用弹层**（弹层会遮住表格）
- 白底、圆角 12、边框 `#F0F2F6`、内边距 14 / 18
- 内部控件 inline 横排，控件间距 26
- 展开动效 160ms（`opacity` + `translateY(-4px)`）
- 入口按钮显示已折叠条件数

### 6.6 KPI 瓦片

- 白底、圆角 14、内边距 13 / 16
- 结构自上而下：30×30 图标块（圆角 9，底 `#F4F5F9`）→ 数值 26px/600 → 标签 12px/`#8A94B0`
- 异常值（欠费、超时）数值与图标块用危险色系
- 最多 4 个，一行放完
- 可在标签行追加一个语义胶囊（如「占 16.7%」）

### 6.7 状态标签

- **6px 圆点 + 13px 文字**，无底色、无边框
- 圆点颜色跟语义色；文字可用 `#4A5168`
- 不用「浅底胶囊」——那是设计稿语言，真实系统里太吵

### 6.8 表单页

- 页头：返回按钮 28×28（圆角 8）+ 标题 17px/500 + `ⓘ` 说明图标
- 说明文字**不放蓝底条**，收进 `ⓘ` 弹层
- 字段分区：每个分区一张白卡（圆角 14、内边距 18 / 20、卡间距 12）
- 分区标题 14px/500，右侧附注 12px 四级色
- 栅格：三列，标签右对齐固定 96px，字段间距 16
- 必填用红色星号前置；校验错误显示在字段下方，不弹 toast
- 底部操作栏：吸底、白底、上边框 `#F0F2F6`、`0 -6px 18px rgba(31,37,64,.05)`
  按钮右对齐（取消 → 存草稿 → 主操作），主操作只有 1 个

### 6.9 范围小计行

- 高 30，单行，不加边框、不加底色
- 左：范围名（13px/500）；中：统计（12px/三级色，数值一级色）；右：本页小计（12px/四级色）

## 七、状态矩阵（每个可交互组件必须齐）

| 状态 | 要求 |
|---|---|
| Default | 底色、文字、边框、圆角、内边距 |
| Hover | 底色变 `#F5F6FF` 或边框变深一档，**不做位移** |
| Active | 底色 `#E4E7FF` |
| Focus-visible | `0 0 0 3px rgba(91,108,255,.14)`，键盘可达 |
| Disabled | 文字 `#C3C9DD`、底 `#F4F5FA`，禁止交互 |
| Loading | 骨架屏占位，**保持原高度**，不跳动 |
| Error | 文字 + 图标，不能只靠颜色 |

---

## 八、禁则

1. 不新增第 4 个强调色
2. 不在业务代码写死色值，一律引用 token
3. 不用同一个色值同时做填充和文字
4. 不为了强调卡片而加深页面底
5. 不用 1px 边框做容器分层（用底色 + 留白）
6. 不加毛玻璃、渐变背景、大面积发光、3D 倾斜
7. 动效上限：hover / press / 展开 150–200ms，不用 spring 大动效
8. 表格行高不超过 52、不低于 40
9. 弹层不用于展示超过 3 个筛选条件（改用就地展开）
10. 入口按钮的权限在渲染层处理（`v-if`），不做「点了再拦」
11. **内容去掉边框后，侧栏必须浅色**——深色侧栏会比内容更重，抢视觉主体
12. 不在数据表末列放常驻操作按钮

## 九、验收清单

- [ ] 字阶只用了 6 档
- [ ] 间距只用了 4/8/12/16/20/24/32/40/48
- [ ] 主按钮每屏 ≤ 1 个
- [ ] 表格行高 46、表头无底色、无斑马纹、hover 为 `#F2F4FF`
- [ ] 金额右对齐 + 等宽数字
- [ ] 卡片圆角 14、控件圆角 8、胶囊 999，无中间档
- [ ] 空态 / 加载态 / 错误态三态齐全
- [ ] 键盘 Tab 顺序合理，focus 可见
- [ ] 正文对比度 ≥ 4.5:1，辅助文字 ≥ 3:1
- [ ] 1280 宽下不出现横向滚动异常
- [ ] 侧栏为浅色，与无边框内容成套

## 十、与原型实现的差异（已知，以本规范为准）

原型已冻结在 2026-11-18。以下几处原型仍是旧值，正式前端按规范走：

| 项 | 原型现状 | 规范要求 |
|---|---|---|
| 状态文字 / 分页字号 | 12.5px | 13px |
| 小角标字号 | 11.5px | 12px |
| 部分旧页卡片圆角 | 10 / 12px | 14px |
| 部分旧页仍带面包屑 | 有 `app-crumb` | 列表页不出面包屑 |
| 旧页表格表头底色 | `#F4F5FC` | 透明 |
| 旧页表格行高 | 48px | 46px |
| 旧页表格末列仍有「详情 / 拆分」按钮 | 有 | 点整行开详情，末列不放按钮 |
| 旧页仍有标题行与蓝底说明条 | 有 | 标题行删除，说明收进 `ⓘ` |

新改造的四个样板页（账单 / 工单 / 业主 360 / 表单）已全部符合本规范。
