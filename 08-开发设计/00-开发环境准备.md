### 为什么 AI 装不了

| 方案 | 卡点 |
|---|---|
| Homebrew | 要在 `/opt/homebrew` 建目录，必须 `sudo` |
| Docker Desktop | 安装时写系统组件、启动时装特权 helper，必须输密码 |
| colima（免 sudo 路径） | 已下载到 `~/.local/bin`，但被沙箱的 exec shim 挡住，报 `lima not found` |

**结论：全局安装必须由你手动执行一次。** 三条路选一条，都在下面。

## 一、方案 A · Docker Desktop（推荐，最省心）

适合：后面还要跑 Redis、后端服务、多个项目的镜像。

```bash
# 1. 下载（arm64 专用包，约 600MB）
#    浏览器打开或命令行下载：
curl -L -o ~/Downloads/Docker.dmg https://desktop.docker.com/mac/main/arm64/Docker.dmg

# 2. 挂载并复制到 Applications
hdiutil attach ~/Downloads/Docker.dmg
cp -R /Volumes/Docker/Docker.app /Applications/
hdiutil detach /Volumes/Docker

# 3. 启动（会弹窗要求授权，输入本机密码）
open -a Docker
```

**首次启动后必做两件事**：

1. 菜单栏鲸鱼图标 → Settings → Resources → 内存调到 **4GB**（默认 2GB 跑 PG + Redis 会紧）
2. Settings → General → 勾选 **Start Docker Desktop when you sign in**（省得每次手动开）

**验证**：

```bash
docker version          # 能看到 Client + Server 两段
docker run --rm hello-world
```

> **许可提醒**：Docker Desktop 对「员工数 > 250 或年收入 > 1000 万美元」的公司需要付费订阅。个人/小团队免费。如果公司规模较大，建议走方案 B。

### 装完可能遇到的两个问题（本机都遇到了）

**① `docker: command not found`**

Docker Desktop 的 CLI 不在默认 PATH 里，它在 `~/.docker/bin/`。加一下：

```bash
echo 'export PATH="$HOME/.docker/bin:$PATH"' >> ~/.zprofile
eval "$(cat ~/.zprofile | tail -1)"
docker --version
```

**② 拉不动镜像（`TLS handshake timeout`）**

国内直连 Docker Hub 基本不通。实测可用的镜像源（2026-11-18）：

| 镜像源 | 探测结果 |
|---|---|
| `docker.m.daocloud.io` | 401（可用） |
| `docker.1ms.run` | 401（可用） |
| `docker.xuanyuan.me` | 401（可用） |
| `dockerproxy.net` | 200（可用） |

> 401 是正常的——registry v2 要求先认证，能返回 401 说明端点活着。

配置到 `~/.docker/daemon.json`（**合并**，不要覆盖已有的 `builder` 配置）：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.1ms.run",
    "https://docker.xuanyuan.me",
    "https://dockerproxy.net"
  ]
}
```

生效：

```bash
docker desktop restart
# 等 daemon 起来
docker info | grep -A5 "Registry Mirrors"
```

看到四个地址列出就说明生效了，之后 `docker compose up -d` 能在十几秒内拉完 `postgres:16-alpine`。

## 二、方案 B · Homebrew + colima（轻量、免费、纯命令行）

适合：只需要命令行 docker，不想装 GUI 程序，或公司有许可顾虑。

### 第 1 步：装 Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

中途会要求输入密码（创建 `/opt/homebrew`），并提示按回车确认。

### 第 2 步：把 brew 加进 PATH

安装脚本结束时会打印一段 `Next steps`，照抄执行。arm64 Mac 通常是：

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
brew --version    # 验证
```

### 第 3 步：装 colima + docker + compose

```bash
brew install colima docker docker-compose
```

`lima` 会作为 colima 的依赖自动装上，不用单独装。

### 第 4 步：启动虚拟机

```bash
colima start --cpu 4 --memory 4 --disk 40
```

首次启动会下载 Ubuntu 镜像（约 500MB），需要几分钟。成功后会打印 `docker context` 切换提示。

### 第 5 步：验证

```bash
docker version
docker run --rm hello-world
docker compose version
```

### 日常启停

```bash
colima start      # 开机后
colima stop       # 关机前（不 stop 会一直占 4GB 内存）
colima status
```

## 三、方案 C · 只装 PostgreSQL（最轻，不装 Docker）

适合：**现在只想验证建表脚本**，不急着上容器。

```bash
# 1. 装（同样需要先有 Homebrew，见方案 B 第 1~2 步）
brew install postgresql@16

# 2. 加入 PATH（brew 不会自动软链到 /opt/homebrew/bin）
echo 'export PATH="/opt/homebrew/opt/postgresql@16/bin:$PATH"' >> ~/.zprofile
eval "$SHELL" -l

# 3. 启动服务（开机自启）
brew services start postgresql@16

# 4. 建库
createdb wy_property

# 5. 验证
psql -d wy_property -c "select version();"
```

装完直接跳到第四节，**跳过 `docker compose up`**，用 `psql` 连本地库即可。

## 五、排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `colima start` 卡在 `Starting the VM...` 超过 5 分钟 | 镜像下载慢，或 vz 驱动异常 | `colima delete` 后重试；仍失败改用 `colima start --vm-type=qemu` |
| `docker: command not found`（colima 装完） | docker CLI 没装或不在 PATH | `brew install docker`；`brew --prefix` 确认路径 |
| `docker compose` 报 `unknown command` | compose 是独立插件 | `brew install docker-compose`，并按提示软链到 `~/.docker/cli-plugins/` |
| 端口 5432 被占 | 本机已有 PG 在跑 | `lsof -i :5432` 找到进程；或改 `docker-compose.yml` 的映射为 `5433:5432` |
| `psql: FATAL: role "aev" does not exist`（方案 C） | 本地 PG 默认用系统用户名建库 | `createuser -s postgres` 后 `psql -U postgres` |
| Docker Desktop 启动报「Docker.app 已损坏」 | macOS 27 的安全策略 | 系统设置 → 隐私与安全性 → 仍要打开 |
| 拉镜像超时（国内网络） | 默认 registry 不可达 | Docker Desktop → Settings → Docker Engine 加 `"registry-mirrors": ["https://docker.m.daocloud.io"]` |
| `run-all.sh: permission denied` | 脚本没执行权限 | `chmod +x 08-开发设计/sql/run-all.sh` |

## 附：我下载了但没能用上的东西

放在 `~/.local/bin/`，可以留着也可以删：

```bash
ls -l ~/.local/bin/
# colima      15MB   v0.10.3
# limactl     34MB   v2.3.0

# 卸载：
rm ~/.local/bin/colima ~/.local/bin/limactl
```

如果你后面装了 brew，这两个可以直接删掉用 brew 版（`brew install colima`），避免版本不一致。
