## 五分钟跑起来

```bash
cd 08-开发设计

# 1. 起库（没有 docker 就跳到第 2 步，自行准备 PG 14+）

# 2. 建表 + 静态检查 + 约束冒烟 + 每日自检
./sql/run-all.sh

# 3. 只跑静态检查（不需要数据库）
node sql/check-ddl.mjs
```

预期输出：`60 张表`、`✅ 无错误`、冒烟 13 条全 `✅`、自检每段 `0 行`。

## 核心结论速览

### 01 数据库

- PostgreSQL 14+，多租户用 **RLS + `FORCE ROW LEVEL SECURITY`**（漏掉 FORCE 等于没做隔离）
- **60 张表**，收费域完整 DDL（bill / payment / payment_allocation / deposit / deposit_txn / invoice）
- 七条铁律：金额 numeric、单据存快照、账期 char(7)、流水只增不改、派生字段不落表、全表 tenant_id、幂等键
- **从 fixture 反推会漏三张表**：租约 `lease`、调账 `bill_adjust`、发票 `invoice` —— 已补
- 命名冲突已约定：`tenant` = 物业公司，房屋承租人 = `lessee`

### 02 流程

- 四阶段三道门禁，**门禁①不通过不许进阶段 1**
- 并行度公式：**并行度 = 无共享写入的模块数**
- 这个项目有两个"必炸"共享文件：`openapi.yaml`（877KB）、`mock-server.mjs`（649KB），**并行前必须先按域拆**
- 每条任务开工前写五行「边界声明」，没写不许开工

### 03 UI

- 问题不在颜色，在 **Element Plus 的骨架从没被改过**（`app.css` 只覆盖 5 类选择器、12 处）
- **不做全站原型精修**，只出 `element-vision.css` + 3 个样板页
- 补密度 token（行高 40/48/56、间距 24、卡片内边距 20）
- 六项可判定验收标准，不靠"够不够高级"这种形容词

### 04 技术栈

- **Java 17 + Spring Boot 3.2 单体 + MyBatis + PG 16 + Flyway**
- 账务手写 SQL，不用 JPA/Hibernate（脏检查会导致更新丢失）
- 不上微服务、不上 MQ（用 Outbox 表）、不上 K8s
- 阿里云 ECS 4C8G + RDS PG 单机起步

## sql/ 里有什么

| 文件 | 作用 | 可重跑 |
|---|---|---|
| `00-init.sql` | schema、扩展、通用函数（`current_tenant_id` / `touch_updated_at` / `deny_mutation`） | ✅ |
| `01-tenant-space.sql` | 租户 + 空间域（community / building / unit / house / parking） | ✅ |
| `02-subject.sql` | 主体域（owner / lessee / lease / house_owner） | ✅ |
| `03-billing.sql` | 计费域（fee_item / bill / bill_adjust / bill_share） | ✅ |
| `04-payment.sql` | 收款域（payment / allocation / prepay / deposit / invoice） | ✅ |
| `05-meter-expense.sql` | 计量 + 费用 + 分摊（表先建，功能后开） | ✅ |
| `06-workorder-asset.sql` | 工单 + 巡检 + 资产 | ✅ |
| `07-hr-audit-system.sql` | 人资 + 审计（按月分区）+ 字典 + 合同公告 | ✅ |
| `20-rls.sql` | 遍历所有含 tenant_id 的表，统一施加 RLS | ✅ |
| `30-seed-minimal.sql` | 最小种子：1 租户 / 1 项目 / 2 套房 / 1 张账单 / 1 笔押金 | ✅ |
| `90-smoke.sql` | **约束冒烟 13 条**，每条都应被数据库拒绝；全在事务里，最后 ROLLBACK | ✅ |
| `daily-check.sql` | **不变式自检 10 段**，每段都应返回 0 行；挂每日巡检 | ✅ |
| `check-ddl.mjs` | 静态检查（无数据库可用）：主键、tenant_id、金额精度、外键、RLS 覆盖 | ✅ |
| `run-all.sh` | 串起上面全部 | ✅ |

**为什么冒烟是"应该被拒绝"**：约束写错了不会报错，只会在三个月后对不上账。所以每条约束都要反着测一遍——插一条违规数据，看数据库是否拒绝。
