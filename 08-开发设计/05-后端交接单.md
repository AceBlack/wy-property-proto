## 三、四个已经踩过的坑（省你两天）

### ① 超级用户永远绕过 RLS

Docker 镜像用 `POSTGRES_USER` 建的 `wy` 是**超级用户**，`FORCE ROW LEVEL SECURITY` 也拦不住。
用超级用户跑冒烟，第 11~13 条会**假通过**——隔离实际失效但不报错。

**所以**：应用连接串必须用 `wy_app`；测试里要 `SET LOCAL ROLE wy_app`。

### ② `CREATE TRIGGER` 没有 `IF NOT EXISTS`

写迁移脚本时第二遍必然报 `trigger already exists`。22 个触发器已改成「先 `DROP TRIGGER IF EXISTS` 再 `CREATE`」。

### ③ bash 里全角标点紧跟变量会报 unbound variable

```bash
echo "通道：$MODE）"     # ❌ MODE）: unbound variable
echo "通道：${MODE}）"   # ✅
```

**这个坑今天踩了三次。** 写 shell 时所有 `$VAR` 后面跟中文标点，一律加花括号。

### ④ 金额比较不能直接比 double

```js
210.64 >= 300.92 - 90.28   // false！实际是 210.6400000000000005 < 210.640000000000015
```

一律转整数分比较：`Math.round(v * 100)`。SQL 侧用 `numeric` 没问题，问题在前端/脚本侧。

**做收费域的数据访问层，不做接口层。**

```
目标：用 MyBatis（或你选的持久层）把下面四条查询跑通，结果与 SQL 手工查询一致。

1. 三率（按项目、按区间）
   口径：收缴率 = 实收 ÷ (应缴原价 − 减免)，排除已作废
   基线：星光天地 85.06% / 翡翠城 81.67% / 锦绣家园 84.42%（2026 全年）
   警告：payable 是应缴「原价」，净应缴 = payable − waive_amount。别减错

2. 账龄分档（未结清按 due_date 分）
   基线：1-30天 525 张 152,236.02 · 31-90天 223 张 65,949.10 · 90天+ 5 张 1,771.45

3. 日结（按 paid_at 分日，现金收入 = Σ 各收款点）
   自检：差额必须为 0

4. 押金三向流水
   恒等式：balance = ΣI − ΣO − ΣD
```

**为什么先做这四条**：它们是财务系统最容易算错、且**有现成基线可比对**的部分。跑通这四条，说明表结构、映射、事务边界都对了。
