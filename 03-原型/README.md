## 六、五条开发约束（违反即返工）

1. **颜色不落地**：页面里禁止写 `#5B6CFF` 之类的色值，一律用 token / `palette` / `statusColor()`。
2. **口径不复制**：欠费、收缴率、在线率等统一调 `utils/api.js`，禁止页面各自 filter/reduce。
3. **数据不直通**：页面禁止 `import from '@/mock'`，一律走 `utils/api.js`。
4. **状态不硬编码**：状态标签一律 `<StatusTag domain="..." :value="..."/>`，新增状态改 `utils/dict.js`。
5. **页面不在 router/index.js 手注册**：只改 `pages.js`，`status:'done'` 自动生效。
6. **校验规则不重写**：表单一律用 `utils/rules.js` 的组合子，禁止页面各写一套正则。
7. **异常态不自拟文案**：空 / 失败 / 无权限 / 超时等一律用 `AsyncBlock` + `EmptyState`，文案见 `/shell/states`。
8. **导出不落地**：页面只调 `exportList()` 提交任务，禁止在页面内生成文件或触发下载。
9. **权限判定不另建映射**：页面/路由的权限判定一律走 `utils/rbac.js`（权限码来自 `permissions.json` 的 `route` 字段）。
   路由守卫必须 `import '@/utils/rbac'` 而非 `@/utils/api`，否则首屏主包会把整个 mock 打进去（实测 1.2MB → 5.4MB）。

## 六之二、异常态九类分支（`/shell/states` 可真实注入演示）

数据层 `delay()` 支持 `setFailMode('timeout' | 'server' | 'denied' | 'expired')`，因此下列状态都是**真实触发**而非静态图。

| 状态 | 触发 | 文案 | 载体 |
|---|---|---|---|
| 空数据 | 成功且 0 条、无筛选 | 暂无数据，可先新增一条 | `EmptyState empty` + 一个主动作 |
| 筛选无结果 | 成功且 0 条、有筛选 | 没有找到匹配的结果，换个条件试试 | `EmptyState search` + 清除筛选 |
| 加载中 | 请求进行中 | 骨架屏 / 表格 loading | `AsyncBlock loading` |
| 加载失败 | 网络异常 | 数据加载失败，请检查网络后重试 | `AsyncBlock error` + 重试 |
| 接口报错 | 5xx | 服务暂时不可用（错误码 500），已记录 | 同上，带错误码 |
| 请求超时 | > 10s | 请求超时，请稍后重试 | 同上 |
| 无权限 | 403 / 数据范围外 | 暂无查看权限，如需开通请联系管理员 | `EmptyState denied`（不给重试） |
| 会话过期 | 401 | 登录已过期，请重新登录 | 全局拦截（原型仅展示文案） |
| 表单校验失败 | 提交时 | 字段红框红字 + 「请检查标红的 N 项」+ 聚焦首个错误 | `FormShell` + `rules.js` |

**边界条件**：0 条 / 1 条 / 满页 / 超长文本（截断 + tooltip）/ 图表全零 / **分母为 0 显示「—」不显示 0%** / 大额千分位 / 跨年账期。

### 三栏骨架 vs 平铺列表：怎么判断要不要升级

**看实体的空间归属字段能落多深**，这是唯一判断标准 —— 只能落到项目级的实体，左树只有 3 个叶子，升级等于把下拉框搬到左侧。

| 可落到的深度 | 字段条件 | 页面 | 结论 |
|---|---|---|---|
| 单元级 | 有 `houseId`，经 `houses` 向上派生 | 17 业主 / 18 账单 / 19 工单 / 21 流水 / 28 房屋 / 29 租户 | 已上树 |
| 车库级 | 有 `parkId`，经 `parkings` 派生区域 | 26 车位 / 27 通行 | 已上树 |
| 仅项目级 | 只有 `communityId` | 20 设备 / 23 巡检计划 / 24 巡检任务 / 25 告警 | **保持平铺** |
| 无空间字段 | 字典型实体 | 22 收费科目 | **保持平铺** |

无空间归属的实体如果占比不小，**不要从树里删掉，而是在项目节点下挂一个专属分支**（如「车位收费（无楼栋）」「公共 / 非入户工单」），否则这部分数据会在树视图里凭空消失。
